# Aahaar Audit

Aahaar Audit is a comprehensive web platform designed to streamline and modernize food safety inspections and compliance audits. With a user-friendly interface and robust architecture, Aahaar Audit ensures proper documentation and tracking of food quality standards.

## Features

- **Dashboard Overview**: Get a clear and concise summary of recent audits, compliance metrics, and action items.
- **Detailed Inspections**: Structured forms and workflows for recording on-site food safety inspections.
- **Evidence Management**: Seamlessly upload, organize, and view images, documents, and other evidence related to audits.
- **Mobile Responsive Layout**: Modern, responsive design optimized for both desktop and mobile devices.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dikshat25/AahaarAudit.git
   ```
2. Navigate into the project directory:
   ```bash
   cd AahaarAudit
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Design

Aahaar Audit features a premium, non-cyber, light-green aesthetic focusing on legibility, accessibility, and modern UI/UX principles, reflecting its food-oriented domain.
